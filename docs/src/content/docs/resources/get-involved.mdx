Welcome to the Rhyza community! Whether you're a seasoned developer or just getting started with open source, there are many ways to contribute to the Rhyza project. This guide will help you find your place in our vibrant ecosystem.

## 🚀 New to Rhyza?

Explore the project

Browse the <LinkOut href='https://github.com/interledger/rhyza'>Rhyza repository</LinkOut> to understand the codebase structure and recent activity.

Join our community

Connect with us on <LinkOut href='https://communityinviter.com/apps/interledger/interledger-working-groups-slack'>`interledger.slack.com`</LinkOut> in the `#rhyza` channel for real-time discussions - Start or join <LinkOut href='https://github.com/interledger/rhyza/discussions'>GitHub Discussions</LinkOut> for deeper technical conversations.

Get hands-on

Try [running the system locally](/integration/testlocal) to familiarize yourself with Rhyza's capabilities. Don't hesitate to ask questions in the `#rafiki` Slack channel!

Make a first contribution

Ready to dive in? Here's how to review good first issues on GitHub if you are new to open source development.

1. Check the Rhyza repository for issues with the <LinkOut href='https://github.com/interledger/rhyza/issues?q=state%3Aopen%20label%3A%22good%20first%20issue%22'>`good first issue`</LinkOut> label.
2. Review our comprehensive <LinkOut href='https://github.com/interledger/rhyza/blob/main/.github/contributing.md'>contribution guide</LinkOut>.
3. Before claiming an issue, ensure you have:

- Read the issue description and comments
- Reviewed any linked documentation or related issues
- Understood the expected deliverables - Confirmed the issue hasn't been resolved in a recent pull request

## 📚 Documentation and learning

Contribute to our documentation

- Improve existing documentation clarity and accuracy
- Create step-by-step tutorials for common use cases
- Develop troubleshooting guides and FAQ sections

Create content

- Write blog posts about your Rhyza integration experiences
- Create video tutorials or demos
- Develop sample applications and code examples
- Share best practices and patterns you've discovered

## 🌟 Community building

Events and engagement

- Attend the <LinkOut href='https://interledger.org/summit'>Interledger Summit</LinkOut> and participate in our annual hackathon
- Organize local meetups, coding sprints, and workshops
- Host online webinars or demo sessions
- Mentor new contributors and help them get started

Hackathons

- Participate in existing hackathons using Rhyza
- Develop innovative applications and integrations
- Create proof-of-concept projects that showcase Rhyza's capabilities
- Collaborate with others on experimental features
