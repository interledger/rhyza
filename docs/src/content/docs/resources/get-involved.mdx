<Card title="Make a first contribution">
  If you are new to open source development, read our contribution guide then check the Rhyza repo for good first issues. Before claiming an issue, ensure you:
    * Read the issue description and comments
    * Review any linked documentation or related issues
    * Understand the expected deliverables and confirm the issue hasn't been resolved in a recent pull request
