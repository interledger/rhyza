---
title: Webhook event types
---

Webhooks notify an FSP when specific events occur in their Rhyza instance, allowing them to integrate Interledger payments with their system and business processes. For example, Rhyza will notify an FSP when one of their customers receives an Interledger payment, at which point the FSP would credit the customer's account on their ledger.

The following is an enumeration of all Rhyza [webhook event](/integration/requirements/webhook-events) types along with their descriptions, which an FSP must listen to and handle.

<div class="overflow-table">

| Value                                                                                            | Description                   |
| ------------------------------------------------------------------------------------------------ | ----------------------------- |
| [`payment_intent.created`](/integration/requirements/webhook-events/#payment-intent-created)     | A payment intent was created. |
| [`payment_intent.completed`](/integration/requirements/webhook-events/#payment-intent-completed) | A payment intent completed.   |
| [`payment.created`](/integration/requirements/webhook-events/#payment-created)                   | A payment was created.        |
| [`payment.completed`](/integration/requirements/webhook-events/#payment-completed)               | A payment was completed.      |
| [`payment.failed`](/integration/requirements/webhook-events/#payment-failed)                     | A payment failed.             |

</div>
