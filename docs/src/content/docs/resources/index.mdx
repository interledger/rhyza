## Before you ask a question

:::tip
Check the [glossary](/resources/glossary) first - a lot of "what does X mean"
questions are already answered there.
:::

A few things worth knowing before digging in:

1. Rhyza uses the term FSP (financial service provider), not ASE - that's a Rafiki v1 term
2. The Admin API and the Open Payments standard use different names for the same resources
3. Most terminology questions trace back to one of those two points
