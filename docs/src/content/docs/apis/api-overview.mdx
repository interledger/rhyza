Rhyza provides:

- A unified REST Admin API to manage your instance and its core resources.
- A REST API for Identity Providers to manage Open Payments interactions with resource owners.

## Admin API

The <LinkOut href="/apis/scalar/admin-api">Admin API</LinkOut> provides comprehensive capabilities to manage your Rhyza instance. Core capabilities include managing assets, wallet addresses, and peering relationships, as well as liquidity management through deposits and withdrawals. It also allows you to manage payment intents, quotes, and payments. The Admin API must be private, accessible only by the FSP.

## Webhooks API

The <LinkOut href="/apis/scalar/webhooks">Webhooks API</LinkOut> describes the events Rhyza sends to your configured [webhook endpoint](/integration/requirements/webhook-events/#specify-a-webhook-endpoint), such as payment intent and payment lifecycle updates.

## Identity Provider Service API

The <LinkOut href="/apis/scalar/idp-service-api">Identity Provider Service API</LinkOut> provides ways for your Identity Provider to signal to your Rhyza instance when and how interactions are completed during the Open Payments Authorization flow, as well as access to information to surface to resource owners during the interaction. The Identity Provider Service API must be private, accessible only by the FSP's identity provider.
