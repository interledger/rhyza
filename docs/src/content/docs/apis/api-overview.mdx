Rhyza provides a unified REST Admin API to manage your instance and its core resources.

## Admin API

The <LinkOut href="/apis/scalar/admin-api">Admin API</LinkOut> provides comprehensive capabilities to manage your Rhyza instance. Core capabilities include managing assets, wallet addresses, and peering relationships, as well as liquidity management through deposits and withdrawals. It also allows you to manage payment intents, quotes, and payments.

## Webhooks API

The <LinkOut href="/apis/scalar/webhooks">Webhooks API</LinkOut> describes the events Rhyza sends to your configured [webhook endpoint](/integration/requirements/webhook-events/#specify-a-webhook-endpoint), such as payment intent and payment lifecycle updates.
