An FSP must add one or more peers to their Rhyza instance before joining and transacting over the Interledger network. Peering establishes the connections needed for the Rhyza instance to interact with another FSP.

:::note
Peers are only required when an FSP wants to transact with another FSP on the Interledger network. If the FSP is using Rhyza solely for transfers between accounts on its own ledger, peers aren't required.
:::

## Prerequisites

Before becoming peers, both FSPs must:

<details>
  <summary>Run an Interledger connector</summary>
  Rhyza ILP connectors know how to speak to each other. It's recommended that
  both FSPs use Rhyza.
</details>

<details>
  <summary>Agree on an asset</summary>
Both FSPs must agree on an [asset](/overview/concepts/accounting#assets) to use for the peering relationship. Peers can set up multiple peering relationships with each another based on different assets.

At least one common asset must be added to both FSPs' Rhyza instance before setting up the peering relationship. For more information, refer to [Assets](/integration/requirements/assets/).

</details>

<details>
  <summary>Exchange static Interledger (ILP) addresses</summary>
  An FSP's{' '}
  <LinkOut href='https://interledger.org/developers/rfcs/ilp-addresses/'>
    ILP address
  </LinkOut>{' '}
  is self-assigned during Rhyza setup and stored locally as the `ILP_ADDRESS`
  environment variable.
</details>

<details>
  <summary>Communicate a connection endpoint</summary>
  The connection endpoint is a URL that the other peer will send packets to.
</details>

<details>
  <summary>Exchange auth tokens for the connection endpoint</summary>
  Incoming and outgoing `authtokens` allow peered FSPs to authenticate packets
  to ensure they originated from each peer's Interledger connector and weren't
  tampered with en route.
</details>

<details>
  <summary>Agree on a settlement mechanism</summary>
  The settlement mechanism that two peers agree to use is what facilitates the
  transfer of actual funds between them. Neither Interledger nor Rhyza provide a
  settlement mechanism.
</details>
