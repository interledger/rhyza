An asset represents an item of value that can be transferred via the Interledger Protocol. Assets in Rhyza are added through the <LinkOut href="/apis/scalar/admin-api#tag/assets/POST/assets">Admin API</LinkOut>.

Assets are unique by their `code` (for example, USD). The `scale` is used as a display property, while the internal ledger operates at a fixed high precision (scale 20).

Use the `POST /assets` endpoint to register a new asset with your Rhyza instance.

<Tabs>
  <TabItem label="Request">
    ```http
    POST /assets
    Content-Type: application/json

    {
      "code": "USD",
      "scale": 2
    }
    ```

  </TabItem>
  <TabItem label="Response">
    ```json
    {
      "id": "b3dffeda-1e0e-47d4-82a3-69b1a622eeb9",
      "code": "USD",
      "scale": 2,
      "createdAt": "2023-11-20T10:00:00Z"
    }
    ```
  </TabItem>
</Tabs>
