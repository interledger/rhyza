Each payment account belonging to an FSP's customers must have at least one associated wallet address for the account to send and receive payments over Interledger and Open Payments. A wallet address serves as a publicly shareable standardized ID for a payment account.

:::note[Wallet address requirements]

- Rhyza must be set up with at least one asset before wallet addresses can be created as each wallet address must have an asset assigned to it.
- Wallet address URLs are treated as case-insensitive, meaning that both lowercase and uppercase variations of the same address are recognized as identical.

:::

Once the wallet address base (`WALLET_ADDRESS_URL`) is set, it can't be changed.

## Create wallet addresses

Wallet addresses can be created using the <LinkOut href="/apis/scalar/admin-api#tag/wallet-addresses/POST/wallet-addresses">`POST /wallet-addresses`</LinkOut> route via the Admin API. However, an FSP can still create a script for bulk wallet address creation.

### Bulk creation via script

One way to batch-create wallet addresses for existing account holders is to write a script that loops through the FSP's list of accounts.

Ensure the script calls the `POST /wallet-addresses` endpoint of the Admin API.

<Tabs>
  <TabItem label="Request">
    ```json wrap
    // POST /wallet-addresses
    {
      "address": "example.wallet.com/sarah",
      "assetCode": "USD",
      "publicName": "Sarah Marshall"
    }
    ```
    We strongly recommend storing at least the `address` in an internal database to be able to reference the account and wallet address later.

  </TabItem>
  <TabItem label="Response">
    ```json
    {
      "address": "example.wallet.com/sarah"
    }
    ```
