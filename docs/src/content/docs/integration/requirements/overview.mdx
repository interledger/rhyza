## Required

Before an entity deploys Rhyza to a production environment and joins the Interledger network, they must:

<table>
  <tr>
    <td>&#x2705;</td>
    <td>
      Be a licensed financial service provider (FSP) in the jurisdictions they
      operate in
    </td>
  </tr>
  <tr>
    <td>&#x2705;</td>
    <td>Add at least one asset to Rhyza</td>
  </tr>
  <tr>
    <td>&#x2705;</td>
    <td>
      Implement a strategy for creating wallet addresses for their account
      holders
    </td>
  </tr>
  <tr>
    <td>&#x2705;</td>
    <td>
      Set up a webhook endpoint and understand how to handle each webhook event
    </td>
  </tr>
  <tr>
    <td>&#x2705;</td>
    <td>Secure their admin services from external access</td>
  </tr>
</table>

## Optional

<table>
  <tr>
    <td>&#x2705;</td>
    <td>
      **Integrate with an identity provider (IdP)**
      <p>
        If the FSP plans to use the Open Payments authorization server provided
        through Rhyza, and/or support Open Payments outgoing payments, they
        **must** integrate with an IdP. An IdP is a system or service that
        stores and manages user identity information, authentication, and
        consent for the FSP's users.
      </p>
    </td>
  </tr>
  <tr>
    <td>&#x2705;</td>
    <td>
      **Add a peer**
      <p>
        A peer is another FSP that you, as an FSP, connect with via Interledger.
        They are likely running their own Rhyza instance. If an FSP is using
        Rhyza solely for transfers between accounts on its own ledger, peers
        aren't required. Otherwise, the FSP must [add at least one
        peer](/integration/requirements/peers) to enable Interledger payments on
        its customers' accounts.
      </p>
    </td>
  </tr>
  <tr>
    <td>&#x2705;</td>
    <td>
      **Provide exchange rates**
      <p>
        If the FSP plans to support cross-currency transactions, they must
        [provide exchange rates](/integration/requirements/exchange-rates) to
        Rhyza. Rhyza supports both pull and push models for obtaining rates,
        which are used to calculate the full cost of transferring value over the
        network.
      </p>
    </td>
  </tr>
</table>
