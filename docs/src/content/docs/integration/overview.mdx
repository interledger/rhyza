Rhyza is a Docker Compose application for financial service providers (FSPs). An FSP is an entity that provides and maintains payment accounts for its customers. An FSP has a number of [responsibilities and obligations](/concepts/financial-service-provider) and is regulated in the jurisdictions it operates. Examples of FSPs include banks, digital wallet providers, and mobile money providers.

:::caution
Rhyza **should not** be used in production environments by non-regulated FSPs.
:::

<Steps>

1. Install the latest version of <LinkOut href="https://docs.docker.com/compose/install">Docker Compose</LinkOut>.

2. Run(?) the Compose file from <LinkOut href='https://github.com/interledger/rhyza/tree/main/docker'>Rhyza's repo</LinkOut>.

3. Work through the [integration checklist](/integration/checklist).

</Steps>

## Testing

For testing purposes, the [Local Playground](/integration/testlocal) lets you run two mock FSPs that automatically peer with one another.
