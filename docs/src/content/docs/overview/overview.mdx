Implementing and maintaining the [Interledger Protocol (ILP)](#interledger) stack can be difficult and time-consuming. Rhyza makes it easy for [financial service providers](/resources/glossary#financial-service-provider-fsp) (FSPs) to integrate with the Interledger network without needing to develop and maintain their own implementations.

Rhyza is open-source software maintained by a dedicated team and freely available to any licensed (FSP) wanting to implement Interledger and [Open Payments](#open-payments) on its users' accounts.

:::tip[Try it out]
The [Local Playground](/integration/playground/overview) allows you to test Rhyza by running two mock FSPs that automatically peer with one another.
:::

## Use cases

### Peer-to-peer payments between FSPs

In the context of Rhyza, peers are FSPs who directly transact with one another. Forming a peering relationship requires FSPs to agree on the currency in which they will transact, decide on a settlement mechanism and cadence, and other details. Interledger creates interoperability between different payment systems and currencies, making it easier for peers to directly transact with one another.

### eCommerce payments

If a merchant accepts Interledger or Open Payments as a payment method, then a customer can pay using their wallet address instead of entering, for example, a credit card number or other personal details on a merchant's site. Rhyza's implementation of Interledger and Open Payments means an FSP's account holders can use their wallet addresses for both one-time purchases and recurring purchases, such as subscriptions, anywhere Interledger or Open Payments is an accepted payment method.

### Web Monetization

With <LinkOut href="https://webmonetization.org">Web Monetization</LinkOut>, site visitors can pay an amount of their choosing to a participating site with little to no interaction. Both the site and the site visitor must have an Open Payments-enabled wallet address to receive and send payments. Rhyza's implementation of the Open Payments standard means FSPs can assign one or more wallet addresses to their account holders' accounts, making these accounts support incoming and outgoing Web Monetization payments right out of the box.

## Interledger

The Interledger network is a network of nodes that have implemented the Interledger Protocol (ILP) stack. Rhyza is a reference implementation of the ILP stack, enabling FSPs to more easily become a node on the network and start sending and receiving payments.

Interledger is designed to be a network on top of existing payment networks that serves as the interoperability layer between them all, forwarding payment messages (packets) while also taking care of currency conversion. Interledger ensures that packets take the fastest and cheapest route from one Interledger node to another.

[Learn more about Interledger](/overview/concepts/interledger)

## Open Payments

Open Payments is an API standard and set of open RESTful APIs that facilitate interoperability in the setup and completion of payments. The standard provides a uniform way to create and manage grants and resources for incoming payments, quotes, and outgoing payments.

By following the Open Payments standard, Rhyza allows FSP customers' accounts to become Open Payments-enabled.

Clients, such as mobile apps, can call the standalone Open Payments resource server to securely retrieve transaction data and initiate payments from the customers' accounts after being authorized by the standalone Open Payments authoritzation server.

[Learn more about Open Payments](/overview/concepts/open-payments)

## System architecture

Rhyza's architecture consists of three primary areas:

- **Core System**: The central logic and storage engine that manages assets, wallet addresses, quotes, payment routing, peering, and webhooks. Rhyza's APIs call this core system to execute actions.
- **Admin API**: The internal REST interface used by the FSP to call the core system for administrative tasks, such as configuring assets, managing peering relationships, and initiating payments.
- **Open Payments APIs**: The external-facing API endpoints (authorization and resource servers) that allow third-party applications to request client authorization and access account resources.
