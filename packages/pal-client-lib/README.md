# PAL Client Library

A TypeScript library for interacting with the PAL (Peers, Accounts and Liquidity) backend service through gRPC.

## Overview

The PAL Client Library provides a simple and intuitive interface for TypeScript applications to communicate with the PAL service. It handles the underlying gRPC communication, serialization, and deserialization, offering a clean API for working with assets and wallet operations.

## Installation

```bash
pnpm add pal-client-lib
```

## Requirements

- Node.js v24 or later

## Quick Start

```typescript
import { PalClient } from 'pal-client-lib';
import { IPalClientAsset } from 'pal-public-types-lib';

// Create a client instance
const client = new PalClient('localhost:50051');

// Initialize the connection
await client.init();

// Create an asset
await client.createAsset('EUR', 2, BigInt(100000), BigInt(10_000_000));

// Retrieve an asset - will return null if not found
const retrievedAsset = await client.getAsset('EUR');
console.log(retrievedAsset);

// Create a wallet

// Create a wallet address alias with a prefix, a suffix and the internal wallet address id - returns void

// Create a wallet address alias with no prefix, a suffix and the internal wallet address id - returns void
await client.createWalletAddressAlias(null, 'pedrobarreto', '123');

*/
```

## API Reference

### `PalClient`

The main class for interacting with the PAL service.

#### Constructor

```typescript
constructor(serverUrl: string, grpcConnectTimeOutMs: number = 5_000)
```

- `serverUrl`: The URL of the PAL gRPC server (e.g., 'localhost:50051')
- `grpcConnectTimeOutMs`: Timeout for gRPC connection attempts in milliseconds (default: 5000)

## Error Handling

The library propagates gRPC service errors. Wrap your calls in try/catch blocks to handle potential errors:

```typescript
try {
  await client.createAsset(asset);
} catch (error) {
  console.error('Failed to create asset:', error);
}
```
